# Data directory

## What's committed vs regenerated

| Path | Committed? | What it is |
|---|---|---|
| `raw/scheme_list.json` | ✅ yes (~6 MB) | The full AMFI scheme list (one row per scheme). Snapshot so pairing is reproducible. |
| `raw/nav/*.json` | ❌ no (~300 MB) | Per-scheme daily NAV history. Regenerated by the download script; git-ignored to keep the repo light. |
| `processed/fund_returns.csv` | ✅ yes (~230 KB) | The analysis-ready dataset: one row per fund with its measured Direct-vs-Regular drag. Built by `notebooks/02_cleaning.ipynb`. |

## Regenerating the raw NAV cache

```bash
python -m src.download          # fetches every paired scheme, skipping cached files
```

The download is incremental and polite (capped concurrency, on-disk cache), so a
re-run only fetches what's missing.

## `processed/fund_returns.csv` schema

| Column | Meaning |
|---|---|
| `fund_name` | Human-readable fund name (plan/option stripped) |
| `fund_house` | AMC, from AMFI metadata |
| `broad_category` | Equity / Debt / Hybrid / Other-Index |
| `scheme_category` | AMFI's granular category |
| `direct_code`, `regular_code` | AMFI scheme codes for the two plans |
| `window_start`, `window_end`, `window_years` | Common comparison window |
| `direct_cagr`, `regular_cagr` | Annualised return of each plan over that window |
| `drag_pp` | `(direct_cagr − regular_cagr) × 100` — the annual commission drag, in pp/yr |
| `drag_pp_winsor` | Drag winsorised at 1st/99th pct (used for modelling) |
| `is_outlier_flag` | True where drag is economically implausible (data artefact) |
